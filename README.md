# ShopEasy — Plataforma de Comercio Electrónico

> Prototipo de tienda en línea desarrollado como proyecto académico para la asignatura de Desarrollo Web.  
> Sala 14 — Planteamiento #8

---

## Descripción

**ShopEasy** es un prototipo funcional de tienda en línea que simula las funcionalidades esenciales del comercio electrónico moderno. El proyecto analiza la arquitectura de una SPA (Single Page Application), el manejo de pagos simulados y la experiencia del usuario en un entorno de compra digital.

---

## Objetivos

- Diseñar e implementar la arquitectura de una tienda en línea
- Simular un flujo completo de compra (catálogo → carrito → pago → confirmación)
- Analizar los retos técnicos y de seguridad del comercio electrónico
- Garantizar una experiencia de usuario intuitiva y fluida

---

## Tecnologías Utilizadas

| Tecnología | Uso |
|---|---|
| **React** | Framework principal (SPA) |
| **Vite** | Bundler y entorno de desarrollo |
| **React Router DOM** | Navegación entre páginas |
| **Context API** | Manejo del estado del carrito |
| **Tailwind CSS** | Estilos y diseño responsivo |
| **JSON Server** | Backend simulado (mock API) |
| **Stripe.js (sandbox)** | Simulación de pagos |
